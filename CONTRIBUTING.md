# Contributing to TravelMate ✈️

Thank you for contributing to **TravelMate**!

## 🚀 Setup Instructions

1. **Fork & Clone**
   ```bash
   git clone https://github.com/YOUR_USERNAME/travelmate.git
   cd travelmate
   ```

2. **Install & Run**
   ```bash
   npm install
   npm run dev
   ```

## 📋 Coding Standards

- Use React functional components with TypeScript types.
- Follow Tailwind CSS utility classes.
