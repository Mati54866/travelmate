# Contributing to TravelMate ✈️

Thank you for contributing to **TravelMate**!

---

## 🚀 Quick Setup

1. **Fork & Clone**
   ```bash
   git clone https://github.com/YOUR_USERNAME/travelmate.git
   cd travelmate
   ```

2. **Install & Run**
   ```bash
   npm install
   npm run dev
   ```

---

## 📋 Guidelines

- Use semantic commit messages (`feat:`, `fix:`, `docs:`, `style:`).
- Test UI responsiveness on mobile viewports.
