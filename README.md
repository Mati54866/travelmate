## <a name="introduction">✨ Introduction</a>

**TravelMate** is an intelligent, AI-powered travel planner and interactive itinerary companion. Designed for modern travelers, TravelMate generates customized day-by-day travel itineraries based on budget, travel style, destination interests, and duration—helping users discover local hidden gems, manage travel budgets, and navigate seamlessly.

---

## <a name="tech-stack">⚙️ Tech Stack</a>

| Layer | Technology |
| ----- | ---------- |
| **Frontend** | React 19, HTML5, Vanilla CSS / Tailwind CSS |
| **Icons & UI** | Lucide Icons, Modern Glassmorphism Design System |
| **AI Processing** | OpenAI API / Claude AI Itinerary Prompting |
| **State & Storage** | LocalStorage / IndexedDB persistence |
| **Tooling & Build** | Vite / Node.js |

---

## <a name="features">🔋 Key Features</a>

- 🤖 **AI Itinerary Generator**: Input destination, duration, budget, and travel preferences to receive structured day-by-day travel plans.
- 💰 **Budget Estimator & Expense Tracker**: Track daily spending, accommodation costs, activity fees, and food budgets.
- 🗺️ **Interactive Destination Explorer**: Discover curated local spots, dining recommendations, and cultural highlights.
- 📱 **Mobile-First Responsive Layout**: Smooth, touch-friendly UI designed for travelers on the go.
- 💾 **Offline Saved Journeys**: Access travel itineraries even when offline.

## <a name="quick-start">🚀 Quick Start</a>

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or `yarn`

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Mati54866/travelmate.git
   cd travelmate
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Set Up Environment Variables**
   ```bash
   cp .env.example .env
   ```

4. **Launch Development Server**
   ```bash
   npm run dev
   ```
